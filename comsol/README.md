# COMSOL Models

Place COMSOL model files, exported settings, and model-version notes here.

Recommended contents:

- `.mph` files for the baseline kinetic, transport, surface-binding, and coupled GFET models.
- Exported parameter sets in `parameters.csv`.
- Exported model settings under `exported_settings/`.
- Model version notes in `model_versions.md`.

If `.mph` files are too large for the repository, store them externally and document the access path, version, and checksum here.
