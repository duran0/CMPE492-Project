# Final Report Notes

The final report is intentionally compiled with `\documentclass[conference,onecolumn,oneside]{IEEEtran}`. The one-column layout is kept for one-page-per-sheet readability in the final submission draft.

If strict IEEE two-column conference formatting is required, change the class line in `final_report.tex` to `\documentclass[conference]{IEEEtran}` and rebuild `final_report.pdf`.
